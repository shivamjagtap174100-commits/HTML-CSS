# Tourism Card

A simple static tourism landing card built with HTML and CSS. It features an ocean background, a tourism heading, a short trip-planning message, and a "Get Started" button.

## Project files

- `TOURISM.HTML` - Page structure and content.
- `TOURISM.CSS` - Card layout, background image, typography, and button styles.

## View the project

Open `TOURISM.HTML` in a web browser. The page loads its styles from `TOURISM.CSS`, which should remain in the same folder.

## Built with

- HTML
- CSS
